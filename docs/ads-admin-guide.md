# Реклама в КАИСТ — гайд администратора

Коротко: **что показывать** настраивается в AdFox, **где показывать** — в коде приложения.
Таргетинг по зданиям/группам/ключевым словам **пока отключён**: на каждом месте
показывается то объявление, которое отдаёт AdFox.

## 1. Где что лежит

| Что | Где |
|---|---|
| Список мест и объявлений | `src/config.ts` → `AD_PLACEMENTS` |
| Загрузчик AdFox | `index.html` (один раз, не трогать; на localhost/превью выключен) |
| Внешний вид баннера | `src/styles/AdBanner.css` |
| Точки показа | `<AdBanner placement="..." />` в компонентах |

Места в приложении:

| `placement` | Где показывается |
|---|---|
| `schedule-top` | над расписанием |
| `students-top` | перед списком одногруппников (в поиске скрыт) |
| `teachers-top` | перед списком преподавателей (в поиске скрыт) |
| `lesson-bottom` | внизу модалки пары |

## 2. Как добавить объявление

1. **AdFox** → `Кампании` → `Создать` (или открыть кампанию клиента).
2. В кампании `Создать баннер`:
   - тип `Основной`, шаблон `Banner Image [context]`;
   - картинку (файл или URL), ссылку (URL перехода), ALT;
   - `Размещение`: отметить нужные места — `schedule-top`, `students-top`,
     `teachers-top`, `lesson-bottom` (можно все);
   - период показа и приоритет.
3. Сохранить и запустить кампанию. **Код приложения не меняется.**

Новые площадки и правки кода нужны только для **новой точки показа** в приложении:
создать площадку AdFox, скопировать `p1/p2` из «Код вставки», добавить место в
`src/config.ts` и вставить `<AdBanner placement="новое-место" />`.

## 3. Как изменить креатив (картинку/ссылку)

`AdFox` → `Кампании` → `Test` → `Баннеры` → нужный баннер → `Изображение`
(загрузить новую картинку) и `URL перехода`. Пропорция задаётся приложением
(`5:1`), поэтому высоту в баннере менять не нужно.

## 4. Как поменять место показа

- **Другой точки в приложении**: перенести `<AdBanner placement="..." />` в нужный
  компонент (например, из `LessonModal.tsx` в `StudentsComponent.tsx`).
- **Другая площадка внутри точки**: заменить `p1/p2` у объявления в `AD_PLACEMENTS`.
- **Скрыть на время**: убрать объявление из списка в `AD_PLACEMENTS` (или поставить
  `priority` ниже и добавить общее).

## 5. Таргетинг (сейчас отключён)

По умолчанию любое объявление показывается на всех своих местах, без условий.
Поля ниже оставлены на будущее — в текущем конфиге они не используются.

В `AD_PLACEMENTS` у объявления можно задать:

| Поле | Смысл | Пример |
|---|---|---|
| `keywords` | показывать, если тема/предмет пары совпадает | `['физика']` |
| `buildings` | показывать в указанных корпусах (1–8), одно или несколько | `[3, 5]` |
| `groups` | показывать указанным группам целиком | `['3439']` |
| `groupDigits` | поразрядно: допустимые цифры на каждой позиции номера группы (1–4). `null`/`[]` — любая цифра | `[[3], [4], [3, 5], [9]]` → группы 3439 и 3459 |
| `priority` | больше = важнее при совпадении | `10` |

- Без `targeting` объявление считается общим и показывается всегда.
- Если подходят несколько — виджет выбирает по `priority`, затем по точности
  совпадения ключевых слов.
- «Здание дня» — корпус, где больше всего пар в выбранный день (при равенстве —
  меньший номер). Оно передаётся в баннер над расписанием.
- В модалке пары ключевое слово — название пары: «Физика» → объявление с
  `keywords: ['физика']`.

Пример «только 3-й и 5-й корпус, группы 34xx»:
```ts
targeting: {
  buildings: [3, 5],
  groupDigits: [[3], [4], null, null],
}
```

Важно: выбор объявления по этим условиям делает **приложение**. AdFox-переменные
(`%user1%`, InPage-параметры) — это параметры запроса/креатива, а не таргет по
группе; для показа нужного клиента по группе/зданию всё равно нужна отдельная
площадка AdFox на каждое такое объявление.

## 6. Как удалить рекламу

- **Убрать объявление конкретного места**: удалить объект из массива в
  `AD_PLACEMENTS`.
- **Убрать насовсем**: удалить баннер и площадку в AdFox; код в приложении можно
  оставить — он просто ничего не покажет.
- **Скрыть все объявления**: закомментировать/удалить `<AdBanner />` в компоненте.

## 7. Внешний вид

В `src/styles/AdBanner.css`:

- `--ad-banner-aspect` — пропорция. Сейчас `5 / 1` (высота = 1/5 ширины).
  Хочешь выше — `4 / 1`, ещё выше — `3 / 1`.
- Ширина всегда равна ширине контента страницы (как у пар, карточек студентов и
  преподавателей): баннер не выходит за поля. Выравнивание задают классы
  `.ad-banner--page` (расписание, 1rem), правила для `.teachers` и
  `.ad-banner--modal` (модалка пары, 1.5rem).
- Крестик `.ad-banner__close` — сворачивает блок в 0px.

## 8. Проверка и типовые проблемы

- Локально реклама **выключена специально**: загрузчик грузится только на боевом
  домене, чтобы тестовые открытия не портили статистику AdFox. Проверять так:
  `http://localhost:5173/?ads=1` (после правки кода — `npm run dev`).
- Открыть приложение, в консоли: `Ya.adfoxCode.getErrorsLog()` — там ошибки AdFox.
- Network: запрос `.../getBulk/v2?...` должен вернуть непустой ответ.
- Пусто/404 — нет активного баннера, не привязана площадка или неверные `p1/p2`.
- `ERR_BLOCKED_BY_CLIENT` — блокировщик рекламы, у части пользователей так и будет.
- Баннер «моргает» — проверь `priority` и `keywords`, подходящих объявлений не должно
  быть больше одного.
- В модалке пары баннер внизу: если контент не помещается, модалка прокручивается
  — это нормально.

## 9. Быстрый чек-лист

- [ ] Площадка в AdFox: тип `Основной`, статус `Активна`.
- [ ] Баннер: тип `Основной`, шаблон `Banner Image`, картинка + ссылка.
- [ ] Баннер привязан к площадке, кампания `Активна`.
- [ ] `p1/p2` из «Код вставки» перенесены в `src/config.ts`.
- [ ] В нужном компоненте есть `<AdBanner placement="..." />`.
- [ ] Проверено в браузере.
